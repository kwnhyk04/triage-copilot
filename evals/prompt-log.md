# Prompt log

Every change to what the model is told, and the dev-split runs that drove it. `eval.prompt_sha()` hashes all of it: the system prompt, the forced-report prompt, the log summary prompt, the brief and the tool definitions. A change gives a new sha, which reruns every cached eval run. Prompts are tuned on the dev split only; results on the test split never drive a change.
